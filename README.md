# Mini Demo

Very small React app (created with Vite) to show what each library does.

| Library | File | What you see |
|---|---|---|
| React Router | `App.jsx` | Switch between "Users" and "Add name" without reloading |
| Axios | `Users.jsx` | HTTP request to the JSONPlaceholder API |
| TanStack Query | `Users.jsx` | Loading spinner, error message and cached list |
| Zustand | `store.js` | Names added in the form appear in the list (green) |
| React Hook Form | `AddName.jsx` | "Name is required" validation |
| Tailwind CSS | all components | Spacing, colors and layout classes |
| daisyUI | all components | `navbar`, `card`, `input`, `btn` components |

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173
